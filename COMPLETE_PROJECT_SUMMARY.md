## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- MongoDB installed
- npm or yarn

### Start Backend
```bash
cd backend
npm install
cp .env.example .env
npm run seed
npm run dev
# Runs on http://localhost:5000
```

### Start Frontend
```bash
cd frontend
npm install
cp env.example .env.local
npm run dev
# Runs on http://localhost:3000
```

### Access Application
Open **http://localhost:3000** in your browser
